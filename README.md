# Neo4j 

Projekt za vježbu iz Neo4j za kolegij Upravljanje Podacima.

## Pokretanje

```
docker compose up -d
```

 - Neo4j Browser: http://localhost:7474 
 - Korisničko ime: neo4j
 - Lozinka: vjezba2026

## Struktura

- screenshots - screenshots rezultata svakog zadatka
- ODGOVORI.md - Odgovori na pitanja iz zadataka
- docker-compose.yaml - Konfiguracija projekta
- queries.cypher - Svi korišteni upiti
